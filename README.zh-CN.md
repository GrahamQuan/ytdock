# YTDock

[English](README.md) · **简体中文**

在 Mac 终端里下载 YouTube 视频、压缩本地视频、给视频加上字幕。按提示选择即可，成品统一保存到系统 **Downloads（下载）** 文件夹。

- **下载视频**：支持普通视频和 Shorts，选择分辨率，可附带原语言字幕。
- **压缩视频**：提供「体积优先」和「画质优先」，保留原分辨率和帧率。
- **加上字幕**：导入本地视频和 SRT 字幕，生成字幕直接显示在画面上的 MP4。

支持 **macOS 14 及以上、Apple Silicon（M 系列芯片）**。

## 安装与启动

### 1. 安装 YTDock

打开「终端」，粘贴以下命令并按 Enter：

```sh
curl -fsSL https://raw.githubusercontent.com/GrahamQuan/ytdock/main/install.sh | bash
```

命令会下载并安装最新稳定版，无需管理员权限。安装完成后不会自动启动程序。

也可以从 [GitHub Releases](https://github.com/GrahamQuan/ytdock/releases) 下载 `macos-arm64.zip` 安装包，**完整解压**后双击 `Install.command`。想先试用，可双击解压目录中的 `Start.command`。

### 2. 准备视频处理工具

YTDock 需要 FFmpeg 才能处理视频。若已安装 [Homebrew](https://brew.sh/)，运行：

```sh
brew install ffmpeg
```

已装好兼容 FFmpeg 的用户可跳过。无需另外安装 Python 或其他程序依赖；缺少 FFmpeg 时，YTDock 会在启动检查中提示。

### 3. 启动中文界面

```sh
~/.local/bin/ytdock --lang zh-CN
```

安装后重新打开终端，通常也可直接使用 `ytdock --lang zh-CN`。还可以在 Finder 中按 **Shift+Command+G**，输入 `~/.local/bin`，双击 `YTDock.command` 启动。

默认界面为英语。在输入页或选择页按 **Ctrl+O**，用 **↑ / ↓** 选择「简体中文」，按 **Enter** 确认。语言设置只对本次运行有效；每次都想使用中文，可使用上面的启动命令。

## 先记住这几个按键

| 想做什么 | 怎么操作 |
|---|---|
| 切换下载、压缩、字幕、任务页面 | Tab 将焦点移至顶部导航，再按 ← / → |
| 进入页面内容或切换输入框、选项框 | Tab / Shift+Tab |
| 选择选项 | ↑ / ↓ |
| 提交输入或确认当前操作 | Enter |
| 返回上一页 | Esc |
| 切换界面语言 | Ctrl+O |
| 取消正在进行的任务 | Ctrl+C，等待清理完成 |
| 退出程序 | 在输入页或选择页按 Ctrl+C |

窗口太小时请放大终端，至少需要 **52 列 × 20 行**。处理期间不能切换页面或语言。

## 下载 YouTube 视频

1. 启动后，在「下载」页粘贴**单个视频链接**，按 **Enter**。
2. 查看视频信息，用 **↑ / ↓** 选择分辨率。同一分辨率如果有不同帧率，会分别列出。
3. 如需字幕，按 **Tab** 移至字幕框，选择「有字幕」。没有可用字幕时不会显示此选项。
4. 按 **Tab** 移至确认框，再按 **Enter** 开始下载。**在分辨率或字幕框中按 Enter 不会开始下载。**
5. 等待下载和文件检查完成，根据「已保存」提示，在 Downloads 中找到视频。

默认选择不超过 1080p 的最高可用分辨率。需要其他画质时，在开始前自行调整。

### 下载带字幕的视频

选择「有字幕」后，程序会保存以下文件：

| 文件示例 | 用途 |
|---|---|
| `视频标题 [ID].mp4` | 不带烧录字幕的视频 |
| `视频标题 [ID].en.srt` | 独立字幕文件，语言后缀随视频变化 |
| `视频标题 [ID]_with-subtitle.mp4` | 字幕已烧录到画面的视频 |

字幕烧录需要额外处理时间，请等待全部完成。已保存的文件不会因为后续烧录失败或取消而删除。

仅提供可确认的**原语言字幕**，优先使用人工字幕，其次是自动字幕，不提供自动翻译。想使用翻译字幕，可以自行准备 SRT，再按下方教程添加。

支持普通视频、Shorts，以及带播放列表参数的单视频链接（只下载当前视频）。暂不支持整个播放列表、频道、直播、尚未开始的首播、需要登录的视频、HDR 或断点续传。无法可靠确定音轨时会提示错误。

## 压缩本地视频

1. 按 **Tab** 将焦点移至顶部导航，用 **← / →** 选择「压缩」。
2. 按 **Tab** 进入输入框，将 Finder 中的视频文件拖入终端，或粘贴文件路径，按 **Enter**。
3. 查看视频信息和将保留的音轨，用 **↑ / ↓** 选择压缩方式。
4. 按 **Enter** 开始，完成后查看体积变化和保存路径。

| 压缩方式 | 适合什么情况 |
|---|---|
| 体积优先（默认） | 更在意文件大小，可以接受明显的细节损失 |
| 画质优先 | 希望保留更多细节，可以接受更慢的处理和较大的文件 |

成品示例：`movie_compressed.mp4`。原文件保持不变，分辨率、宽高比和帧率也会保留，包括 60fps。

**压缩后不保证比原文件小。** 完成后会显示前后大小；如果成品更大，会提示「体积增加」，仍保留结果供你选择。

一次只处理一个文件，支持 MP4、MOV、MKV、WebM 等常见格式。多音轨视频仅保留页面提示的音轨，不保留原文件中的独立字幕或封面。HDR、旋转视频等不支持的文件会在检查时提示。

## 给本地视频加上 SRT 字幕

适合已有字幕文件，或已经用其他工具翻译好字幕的情况。烧录后的字幕会直接显示在画面上，播放时无需另行加载，也无法关闭。

1. 在顶部导航选择「字幕」，按 **Tab** 进入内容。
2. 在两个输入框中分别填写**视频路径**和 **SRT 字幕路径**，用 **Tab / Shift+Tab** 切换。可以直接从 Finder 拖入文件。
3. 按 **Enter** 检查文件，查看视频信息、字幕条数和将保留的音轨。
4. 保持选中「确认继续」，按 **Enter** 开始；需要修改时，按 **Esc** 返回。
5. 完成后，在 Downloads 中找到 `原文件名_with-subtitle.mp4`。

请使用 **UTF-8 编码的 SRT 文件**，大小不超过 20 MB。支持自行准备的不同语言字幕；本功能不翻译、不上传文件，保留字幕文字、换行和分段，也不修改原视频或原字幕。

若提示字幕时间错误、缺字或文字溢出，请按提示修正字幕或字体后重试。字幕结尾仅略超出视频时长（最多 2 秒）时，会自动截短并提示。

## 查看结果与取消任务

所有成品默认保存在系统 **Downloads（下载）** 文件夹，完成提示会显示实际路径。同名文件会自动添加数字后缀，例如 `movie_compressed (1).mp4`，不会覆盖已有文件。

在顶部导航选择「任务」，可以查看**本次运行**的任务记录：

- **↑ / ↓** 选择记录，**Enter** 查看保存路径、失败原因或取消结果。
- **Page Up / Page Down** 滚动详情，**Esc** 返回列表。
- 记录在退出程序后清空，不支持任务排队或恢复处理。

处理中按 **Ctrl+C** 可取消。请等待临时文件清理完成后继续操作；源文件和已经保存的成品会保留。成功后可继续输入下一项，失败或取消后会保留原输入，方便重试。

## 升级与卸载

先退出所有 YTDock 窗口，再在终端运行。

查看当前版本：

```sh
~/.local/bin/ytdock --version
```

升级到最新稳定版：

```sh
~/.local/bin/ytdock --lang zh-CN --upgrade
```

升级时请保持终端打开，等出现完成提示后再启动。若旧版本不支持 `--upgrade`，重新运行本文开头的安装命令，或下载新版安装包并双击 `Install.command`。

卸载：

```sh
~/.local/bin/ytdock --uninstall
```

也可双击解压目录中的 `Uninstall.command`。卸载会保留已下载和处理的视频，以及外部 FFmpeg。

## 常见问题

遇到启动或处理问题，先运行检查：

```sh
~/.local/bin/ytdock --lang zh-CN --check
```

| 问题 | 处理方式 |
|---|---|
| 提示 `ytdock: command not found` | 重新打开终端，或使用完整命令 `~/.local/bin/ytdock` |
| 缺少 FFmpeg、ffprobe 或编码器 | 安装完整 FFmpeg；使用 Homebrew 时运行 `brew install ffmpeg`，已安装则尝试 `brew upgrade ffmpeg` |
| 普通下载可用，但字幕烧录失败 | 按错误提示检查 FFmpeg 的字幕支持及字体；也可以先选择不带字幕下载 |
| 提示已有实例运行 | 退出其他 YTDock 窗口，包括停留在输入页的窗口，再重试 |
| macOS 阻止首次打开 | 安装包尚未完成 Apple 公证；确认来源后，在系统设置「隐私与安全性」中按提示允许打开 |
| 视频下载失败 | 检查网络和视频是否公开，确认链接属于支持范围，并尝试升级 YTDock |
| 提示找不到本地文件 | 从 Finder 重新拖入文件；含空格的路径也可以用成对引号包住 |
| Downloads 无法写入或磁盘空间不足 | 检查下载文件夹权限，释放空间后重试 |
| 想查看失败的具体原因或已保存路径 | 打开「任务」页，选中记录后按 Enter |

FFmpeg 安装在自定义位置时，可这样启动：

```sh
~/.local/bin/ytdock --lang zh-CN --ffmpeg-dir "$HOME/tools/ffmpeg/bin"
```
