# 实现与验证记录

## 0.5.1 语言选择页

Ctrl+O 打开中英双语语言选择页，选中当前语言；↑↓ 选择，Enter 确认，Esc 取消。返回时保留原布局、输入、光标及选项。替代 F2 直接切换，任务期间不可打开。19 项语言及 UI 测试通过，Ruff 静态和格式检查通过。下方为历史版本记录。

## 0.5.0 中英界面

默认英语，`--lang en` / `--lang zh-CN` 设置本次运行语言。输入和选择页 F2 即时切换并保留输入与选项；任务期间固定语言，工作进程继承语言。成功、取消、依赖及处理错误均使用所选语言；标题、路径、文件名保持原样。README.md 为英语，README.zh-CN.md 为简体中文。

完整回归 154 项通过，新增双语界面渲染、占位符、默认语言、F2 状态保留、命令行帮助与工作进程语言验证。双语 README 链接与版本检查通过。

## 0.4.1 文件名优化

两种压缩模式统一输出 `原文件名_compressed.mp4`；重名继续使用 ` (1)` 等数字后缀，保留原文件名中的文字，不添加中文模式名。

本次命名及真实工作进程重名发布两项测试通过，Ruff 检查通过。冻结程序构建完成；0.4.1 隔离安装自检被当前正在运行的 yt 实例阻止，未停止该实例，未重复安装/卸载验收。下方完整验收为 0.4.0 历史结果。

压缩页默认选中「体积优先」，Enter 直接使用该选项；按 ↓ 可切换到「画质优先」。下方 0.4.0 验证描述为历史行为。

## 压缩模式实现

- 下载/压缩输入页 Tab 切换，恢复 URL 草稿；压缩选择页 Esc 返回路径页，路径页 Esc 返回下载。
- 路径仅解析不执行，检查本地单文件、SDR/色彩/旋转等元数据；主视频和默认音轨明确显示。
- 两种 CRF/preset/AAC 配置，保留实际尺寸、SAR、30/60/59.94fps；完整解码后排他发布，源文件身份在读取、处理与发布前复核。
- 复用工作进程、进程组取消、所有权清理和单实例锁；成品更大也保留并明确提示。

- 安装版完成公开视频 jNQXAC9IVRw 的解析、真实下载、验证发布及再次下载取消清理，原下载流程回归通过。
- 安装目录实际占用 57,836 KiB（约 56.5 MiB），压缩包约 28.5 MiB，不含外部 FFmpeg。
- 启动器通过 PTY 模拟双击时的精简 PATH；尚未在另一台 Mac 的 Finder 上人工验收。

## 外部依赖基础

- 内置 Python、QuickJS 2026-06-04、yt-dlp、yt-dlp-ejs、Foundation 桥与 UI。
- 新包不再携带 FFmpeg、ffprobe、x264、dav1d、pkgconf 及其专用源码/构建脚本；移除 meson/ninja 打包依赖，保留一键打包。
- `--ffmpeg-dir`、`--ffmpeg`、`--ffprobe` 支持显式路径。环境变量现已统一为 `YTDOCK_FFMPEG_DIR`、`YTDOCK_FFMPEG`、`YTDOCK_FFPROBE`，旧名不再支持。
- 显式候选优先，其次 PATH 和常见 Homebrew 位置；优先配套程序，不兼容候选继续查找。显式回退有提示，全部失败展示具体原因。
- 检查两个程序存在且可执行，以及 H.264/VP8/VP9/AV1 软件/AAC/Opus/Vorbis 解码能力；FFmpeg 还需 libx264/AAC 编码器和 fps_mode。
- 选定程序的绝对路径传给工作进程。QuickJS 继续使用包内私有路径。
- 安装后提示外部依赖状态；FFmpeg 检查失败不回滚程序安装。不自动安装、更新或卸载外部工具。
- 卸载只删除自有程序和未被改动的启动器/命令，保留下载视频和外部 FFmpeg。
