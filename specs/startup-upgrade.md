# 版本、升级与启动反馈

状态：开发源码已实现；本次不重新打包。公开 v0.7.1 安装包未包含本次新增命令和启动页，未验证真实跨版本二进制升级。

## 命令边界

- `--version` / `-v` 输出 `YTDock <version>` 并返回 0，不检查 FFmpeg、不联网、不进入全屏。版本取项目分发元数据；未安装的源码检出回退读取 pyproject.toml。未来 PyInstaller 构建显式收集 ytdock 分发元数据，构建脚本共用版本读取函数。
- `--upgrade`、`--install`、`--uninstall`、`--check` 和版本查询互斥。帮助、版本查询、依赖检查、安装、卸载与升级使用普通输出。
- 开发环境中的 `--upgrade` 明确拒绝，不联网、不修改环境；只有拥有合法安装记录的发布安装版可升级。

## 升级

1. 根据当前可执行文件及安装记录确认原安装 prefix，复用全局锁，阻止所有其他实例（包括等待输入的实例）。
2. 查询 GitHub latest 稳定 Release 端点，再验证非草稿、非预发布及版本格式。显示本地与远端版本；本地相同或更高时结束，不下载、不降级。
3. 仅接受 macOS 14+ / arm64 对应资产和准确的仓库 Release 下载地址；HTTPS 下载与重定向，限制元数据、归档和展开大小，校验 SHA256。拒绝路径穿越、不安全归档及错误版本、所有权或文件清单。
4. 下载与验证全部在私有临时目录进行，失败不改安装。下载阶段 Ctrl+C 取消并清理；清理失败报告路径。
5. 复制当前已验证程序到临时更新器目录，启动独立更新进程。通过 pass_fds 传递同一全局锁的打开文件描述符以及父进程存活管道；旧进程的写端仅在进程退出时关闭。更新器等待 EOF 才替换，期间全局锁持续有效，不出现释放再抢锁的空档。
6. 更新器复用 install_bundle 的 prefix 锁、所有权检查、临时副本、备份与回滚；交接及替换阶段忽略普通中断直到安全收尾。保留原 prefix、安装记录中的现有配置及外部配置，保护视频和外部 FFmpeg。未知或已修改的程序文件不会被覆盖。
7. 不自动启动升级后的 UI。独立更新器完成后输出结果和启动命令；原调用进程先退出，因此完成提示可能出现在 shell 提示符之后。失败由更新器输出，回滚失败报告备份残留位置。

现有 Ctrl+O 语言选择仍为进程内状态，未新增语言持久化。升级沿用 `--lang` 的反馈语言，不清除已有配置；没有持久化的旧语言选择无法跨进程恢复。强制杀进程或断电不保证即时清理。

## 启动

- 交互入口完成参数解析后尽早打印标题及 Python 检查说明，然后进入现有唯一的全屏 Application；这是入口执行后的反馈，不涵盖 PyInstaller 启动、macOS Gatekeeper 或系统加载可执行文件之前的等待。
- Python 组件元数据与模块发现、QuickJS、FFmpeg、ffprobe、Downloads、全局锁、残留任务恢复、界面模块依次检查。成功才显示 ✓；当前检查使用活动指示器，待处理项弱化，失败显示 ✗。
- 耗时检查在后台线程执行；QuickJS 和 FFmpeg/ffprobe 使用可取消的独立进程组。保留完整编码/解码能力验证及候选回退，只有最终兼容组合确定后才确认 FFmpeg/ffprobe 成功。
- 不模拟百分比、不加人为等待；原地重绘不超过 10Hz。窄窗口换行并使当前检查位置可见，底部保留取消提示；中英文和无颜色终端均可辨识状态。
- 全部成功后直接进入四 Tab；沿用原输入、焦点、任务和取消行为。未恢复成功的残留任务明确报告，保留其路径供检查。
- Ctrl+C 终止检查进程组；已经开始的所有权确认清理等待完成后才结束。重复 Ctrl+C 不跳过收尾。退出释放全局锁并恢复终端；失败后在普通终端重印完整检查报告，避免备用屏幕隐藏错误。
