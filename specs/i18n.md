# 中英双语界面（0.5.1）

- CLI 默认英语，不根据操作系统自动切换。
- `--lang en` / `--lang zh-CN` 设置本次运行语言，作用于帮助、检查、安装/卸载提示和交互页面。
- 输入页与选择页使用 Ctrl+O 打开独立语言选择页，标题和按键提示固定中英双语。
- 打开时选中当前语言；↑↓ 只改变高亮，Enter 确认，Esc 取消。返回原页面保留文字、模式、光标和已选项。
- 语言页不响应模式切换，确认不会触发原页面提交；Ctrl+C 仍退出。
- 语言只作用于当前运行，不写入配置；重新启动默认英语。
- 处理阶段不提供语言切换，工作进程继承任务启动时的语言。
- 翻译覆盖模式名称、操作提示、选项、大小未知/估算、进度阶段、成功、取消及安全错误信息。
- 视频标题、路径、音轨标签、文件名和内部操作/阶段标识保持原样。
- 压缩默认「体积优先」/ Smaller file，成品仍为 `xxx_compressed.mp4`。
- README.md 使用英语，README.zh-CN.md 使用简体中文，相互链接；发布包同时包含两份文档与翻译目录。
- 验证默认语言、两种 --lang、Ctrl+O 确认/取消和状态保留、翻译占位符、工作进程语言、原下载/压缩回归，以及冻结包翻译资源。

## 翻译文件结构

每个语言一个 `src/ytdock/locales/<语言代码>.json`，使用相同的英文标识键。默认 `en`；按文件自动发现语言，`language.name` 是该语言的显示名称。缺失文案回退英语，未知键报错，插值只处理文案模板。语言选择页和 --lang 参数均从发现的语言列表生成；打包递归收集全部语言文件。
