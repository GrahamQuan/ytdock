# 统一键盘焦点

此规格取代 download-panel-navigation.md 中的 W/S 规则，以及历史规格的 Tab 直接切页规则。

Tab / Shift+Tab 在当前页顶部导航与可交互内容间双向循环。无字幕隐藏并跳过字幕框。进入下载选择页默认分辨率框，其后为字幕框、确认框；只有确认框 Enter 提交。W/S 不再绑定，输入框 W/S、方括号和左右光标正常。

导航获得焦点时用 ←→ 循环四页，切页后仍在导航，Tab 进入该页第一个区域。主页面状态、输入光标和选项保留。各内容框仅通过边框颜色标识焦点，标题不加方括号，导航用居中高亮边框标记焦点，当前主页面始终带方括号。

字幕输入页 Tab 遍历视频路径与字幕路径，不再用上下切换。其余输入、选择及任务列表/详情遵循相同导航规则。语言弹窗独占按键，关闭恢复原焦点。处理及取消清理时导航不可聚焦，Ctrl+C 等待清理后恢复输入页。

所有页面继续使用单一全屏 Application。窗口不足显示尺寸提示，缩放恢复内容。实际验证范围在交付中记录；本次不提交、推送、发布或重新打包。

## 实际验证

完整测试套件 356 项通过（79.95 秒）。覆盖四页导航双向循环、输入左右编辑及 W/S/方括号、隐藏字幕跳过、确认提交边界、语言弹窗返回、任务与取消清理；PTY 备用屏幕和终端恢复测试通过。已查看中英文 DummyOutput 渲染网格的确认框、焦点标题和快捷键；现有窄窗口/缩放测试通过。小于可显示尺寸仍提示扩大窗口，不宣称任意尺寸可完整展示。未重新打包或验证新安装包。
