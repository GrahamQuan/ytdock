# Original-language subtitles (YTDock)

下载分辨率页可用 S 打开「不带字幕 / 有字幕」。每个新视频默认无字幕；同一视频返回修改时保留分辨率和字幕选择，处理期间禁用设置。没有可用的原声同语言字幕时不显示入口；翻译字幕不参与选择。

原声同语言人工字幕优先、原生自动字幕后备，显示来源和语言代码。不翻译、不做语音识别。参考 download-yt-video-with-subtitles 的标签清理、按单词分段、42 字符单行、按字符比例分配时间和重叠截断逻辑。毫秒分段不能无声丢弃文字。有效 SRT 不为空、时间有效且不重叠。

有字幕模式：下载媒体和字幕 → 源视频标准 MP4 处理及完整检查 → 整理/检查 SRT → 独占发布源视频并通知 → 独占发布 SRT 并通知 → 自动烧录 → 完整解码与抽帧对比 → 独占发布烧录文件 → 清理 → 全部完成。

输出：`xxx.mp4`（H.264 + AAC）、`xxx.<language>.srt`（实际用于烧录的处理后字幕）、`xxx_with-subtitle.mp4`（HEVC + AAC）。源视频沿用标题与视频 ID 清理规则；源视频发生重名时，后续输出沿用实际 basename，并在各自发布时再次独占处理冲突。只保留三个成品，不输出原字幕、元数据或文稿。

烧录参数：libx265、CRF 27、preset medium、hvc1、yuv420p、faststart，AAC 复制、无音频不添加音轨，不改分辨率、宽高比或实际帧率。白字、Outline=0.7 黑描边、Shadow=0、WrapStyle=2。以 Arial 16 的参考样式起步，过宽文本根据渲染检查缩小字号以适应画面。用户路径不进入滤镜字符串；在独立临时目录使用固定字幕文件名。

字幕功能单独预检 libx265、HEVC 解码、subtitles/libass 与实际字体渲染。能力缺失时可以选择不带字幕，不自动安装软件。所有 FFmpeg 子进程属于可取消工作进程组。下载、整理、烧录、检查显示真实阶段，烧录依据处理时长报告进度和 ETA。

主进程记录每份已发布文件。任何后续失败/取消均保留它们，报告实际路径及失败项；只删除本次任务的隐藏临时目录。发布 SRT 失败不会声称两份文件都成功。重复 Ctrl+C 不跳过清理，取消退出码 130。沿用单实例锁，不提供继续烧录或队列。

验证包括字幕轨选择及翻译排除、界面隐藏/保留、时间轴、横竖屏、30/60fps、有无音频、实际 HEVC 编码与抽帧、部分发布与取消保护、原下载与压缩回归。打包提供 ZIP/tar.gz 和校验文件；不 commit、不 push、不发布 Release。在线验证与未完成覆盖在交付时据实记录。

- 最新处理顺序：读取原始字幕 → 按实际视频时长检查每条时间，允许结束时间最多超出 2000 毫秒并截短（必须在视频内开始）→ 原有重叠归一化 → 单行 42 字符重分段 → 文字完整性和严格 SRT 检查。最终 SRT 不允许超出视频时长。相同起始时间导致有效文字丢失、非正时长、完全位于视频外和超出容差均报错，不静默删除。

## 原声音轨与字幕语言修复

- 音轨先按 yt-dlp 原声标记（original / language_preference）确定来源，再比较兼容性和码率。负语言优先级本身不代表配音。选择顺序为明确原声、唯一音轨、按明确原始语言唯一匹配非配音音轨；其他情况拒绝猜测。详见 [音轨选择修复](audio-selection.md)。
- 字幕匹配原声语言，人工优先、自动后备；明确排除所有 `tlang` 翻译请求，包括空值。原声语言未知时仅允许无翻译、单一语言的原生自动字幕提供语言依据，不从人工翻译字幕推断。
- 私有固定字幕路径改为 `captions.srt`，发布后缀从字幕描述中读取并校验语言代码，例如 `.en.srt` / `.es.srt` / `.ja.srt`；不把区域代码或 `-orig` 注入路径。不覆盖旧文件，保留已有取消和部分发布保护。
- 只有音轨确认为原声时显示 `Audio: Original` / `音轨：原声`；字幕文案不再限定英语。字幕时间、42 字符分段和烧录编码约定不变。
- 真实问题视频 `shhFyL2oKHw`：之前选择阿拉伯语配音 `140-0`；现选择英文原声 `140-19` 并匹配原生英文自动字幕 `en`。格式编号只用于本次验证，不硬编码进规则。
- 回归包括 en-US、es、ja、zh-Hans、es-419 的语言匹配、人工/自动优先级、翻译排除、原声 Opus 优先于配音 AAC，以及 en/es/ja 的发布命名和取消保护。其他语言的真实在线视频尚未逐一验证，字体仍需 FFmpeg/fontconfig 提供对应字形。

- 本次开发版真实工作进程验证已通过：`shhFyL2oKHw` 360p 原声 `140-19` 下载、原生 `en` 自动字幕处理、源 MP4 与 `.en.srt` 先发布、HEVC 烧录、完整解码/字幕抽帧及三个文件安全发布。产物位于隔离临时目录，用户 Downloads 文件未改动。未重新打包、commit、push 或发布 Release。
