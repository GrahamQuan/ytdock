# 外部 FFmpeg 契约（0.3.0）

按用户计划执行：Python、QuickJS、yt-dlp/ejs 和 UI 保持内置，FFmpeg/ffprobe 使用外部安装。

- 新发布包不携带 FFmpeg、ffprobe 或仅用于构建它们的编码库、源码、构建工具；一键打包保留。
- 显式命令行路径优先，其次环境变量（未提供命令行路径时）、PATH、常见 Homebrew 位置。
- 优先配套工具，验证两个可执行程序及所需编码/解码能力；不兼容候选继续查找，全部失败列出具体原因。
- 显式候选回退时提示，不静默忽略用户路径；选定后将绝对路径传入工作进程。
- 安装后执行依赖检查；检查失败不回滚程序安装。不自动安装、更新或卸载外部 FFmpeg。
- 卸载仅删除本工具拥有的程序和启动器，保留视频与外部工具。
- 测试缺失、缺少 ffprobe、能力不足、无执行权限、多版本、指定路径和精简 PATH。
- 发布包验收真实下载、转码、取消、安装、升级与卸载，并测量安装占用和 ZIP 大小。

此契约替代原规格第 12 节中“内置 FFmpeg/ffprobe”的要求；其余媒体处理与输出保护规则保持有效。
