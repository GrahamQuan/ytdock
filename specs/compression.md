以下计划面向当前独立 Python CLI，新增「压缩」模式，复用现有 UI、外部 FFmpeg、取消清理和安全发布机制。

## 1. 模式切换

- 默认进入「下载 YouTube」。
- 输入页提供 `Tab 切换模式`，可进入「压缩视频」，再切回「下载」。
- 压缩模式作为独立页面，保留下载页尚未提交的 URL；返回时恢复。
- 压缩选择页按 `Esc` 返回路径输入页，路径输入页按 `Esc` 返回下载模式。
- 处理任务期间不能切换模式，同一时间只运行一个下载或压缩任务。

示例：
```text
YTDock    下载 / [压缩]

╭────────────────────────────────────────────╮
│ 粘贴视频文件路径…                         │
╰────────────────────────────────────────────╯
Enter 继续 · Tab 返回下载 · Ctrl+C 退出
```

## 2. 输入与源文件检查

- 接收一个本地视频文件的绝对路径，支持空格、中文、`~` 和首尾配对引号。
- 支持 macOS 从 Finder 拖入终端产生的转义路径；仅解析路径，不执行 shell。
- 第一版只处理单个文件，不支持目录和批量任务。
- 使用 ffprobe 检查视频编码、尺寸、帧率、时长、音轨和文件大小。
- 文件不存在、不可读、无视频流或格式不支持时，明确提示并允许重新输入。
- 第一版仅支持 SDR；HDR、无法可靠处理的色彩或旋转信息明确拒绝，避免错误输出。

## 3. 选择压缩方式

输入成功后显示源视频信息，再选择：
```text
示例.mp4 · 1920×1080 · 60fps · 12:34 · 800 MB

选择压缩方式
❯ 体积优先 · 默认
    压缩较强，可能明显损失细节

  画质优先
    尽量保留细节，处理较慢，文件可能较大

保留源分辨率和帧率
输出：系统 Downloads · MP4
↑↓ 选择 · Enter 压缩 · Esc 返回
```

两种模式使用以下参数：

| 设置 | 体积优先 | 画质优先 |
|---|---|---|
| 视频编码 | libx264 | libx264 |
| CRF | 30 | 23 |
| preset | superfast | medium |
| 音频 | AAC 128 kbps | 兼容 AAC 时复制，否则 AAC 192 kbps |
| 像素格式 | yuv420p | yuv420p |
| MP4 设置 | avc1、faststart | avc1、faststart |

补充约定：

- 沿用前面讨论的两组参数；体积优先模式中的 `superfast` 偏向处理速度，并非最佳压缩效率。
- 两种模式均保留源视频尺寸、宽高比和帧率，不添加 `-r 24`；60fps 视频保留其实际帧率。
- 无音频源保持无音频。
- 第一版保留主视频和默认音轨；多音轨文件在开始前明确提示仅保留哪一轨。
- 不复制字幕、封面及其他附加流。
- 明示“压缩后不保证比原文件小”，不承诺固定压缩比例。
- Enter 直接开始，无额外确认。

## 4. 处理与进度

- 主进程负责 UI，独立工作进程负责 FFmpeg 和成品检查。
- 使用结构化参数启动程序，不拼接 shell 命令。
- 显示真实阶段：读取信息 → 压缩 → 检查文件 → 保存完成。
- 根据 FFmpeg 已处理时间和源时长显示压缩进度；未知时使用活动指示器。
- 原地刷新，每秒不超过 10 次。
- 沿用现有百分比规则；压缩达到 100% 后仍需完成检查和保存。
- 成功后显示输入大小、输出大小、体积变化及最终路径，返回压缩输入页。

## 5. 输出与成品检查

- 默认保存到系统 Downloads。
- 文件名（0.4.1 更新）：两种模式统一使用 `原文件名_compressed.mp4`，不添加中文模式后缀。
- 重名自动添加数字后缀，绝不覆盖源文件或已有文件。
- 在 Downloads 下的本次任务隐藏临时目录内完成处理。
- 检查文件非空、MP4 容器、H.264、yuv420p、音频、尺寸、帧率和时长，并进行完整解码检查。
- 检查通过后在同一文件系统内以不覆盖的方式发布，再清理临时目录。
- 如果成品更大，仍保留已完成文件，明确显示“体积增加”，不声称压缩成功减小体积。

## 6. 中断与失败清理

- 输入和选择阶段按 `Ctrl+C`：退出程序。
- 读取、压缩和检查期间按 `Ctrl+C`：
  1. 显示“正在取消并清理…”。
  2. 停止工作进程及全部子进程，等待退出，超时强制终止。
  3. 删除确认属于本次任务的全部半成品。
  4. 清理成功后显示提示，以退出码 130 退出。
- 重复按 `Ctrl+C` 不得跳过清理。
- 出错时同样执行清理，然后返回压缩输入页。
- 清理失败报告残留路径，不声称已清理。
- 永不删除源视频、已有文件或已成功发布的成品。
- 下次启动清理已确认失效的临时任务，复用现有所有权与单实例保护。

## 7. 验证与交付

- 验证下载与压缩切换、返回、输入保留及连续处理。
- 验证中文、空格、引号、拖入路径、非法路径和多文件输入。
- 使用生成样本测试两种模式，以及 30/60fps、竖屏、无音频、非 AAC 音频。
- 验证源文件不变、重名不覆盖、输出更大提示。
- 验证压缩和检查期间取消、磁盘写入失败及子进程异常后的清理。
- 回归原有 YouTube 下载功能。
- 更新规格、README 和一键打包产物，验证安装、启动与卸载。

**验收目标：用户可在「下载」和「压缩」之间切换，通过文件路径选择两种压缩方式；保留源文件，取消不留半成品，完成后可继续处理下一项。**
