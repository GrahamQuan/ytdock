# 全屏界面与任务记录

状态：已实现，验证范围见下文。本规格更新旧规格的页面生命周期和运行内任务记录约定。

- 一个 prompt_toolkit Application 使用备用屏幕；页面保留布局和状态，退出恢复终端。不执行外部 clear。帮助、依赖检查、安装和卸载保留普通输出。
- 四 Tab：下载 → 压缩 → 字幕 → 任务 → 下载。Tab 向右、Shift+Tab 向左，双向循环；不绑定左右方向键，输入框左右光标移动保持不变。当前页使用强调色、加粗及方括号。输入、光标、焦点、选项保持；处理及清理期间禁止切换。
- Ctrl+O 打开语言页，Enter 应用、Esc 放弃，恢复原页焦点。各页方向键按输入或列表上下文处理。
- 有效提交开始创建内存记录；读取、选择、处理及格式重新选择共用记录。处理前返回标为未开始。空输入不创建记录。无队列、并发或续传。
- 任务最新在前，Enter 打开详情、Esc 返回，方向键及翻页键滚动。详情包括类型、输入、时间、耗时、状态、保存路径、失败阶段与原因、取消清理结果及残留路径。
- 由结构化阶段、保存和任务结果事件更新记录，不解析提示文字推断状态。部分保存后失败仍为失败，并说明已保留文件。
- 成功清空本次输入；失败及取消保留输入；都返回当前功能输入页。每个模式的通知保留到下一次提交，详情保留到程序退出。
- Ctrl+C 在处理时等待全部子进程停止及清理，重复按键不跳过；其他页面退出。异常退出也恢复终端并等待适用的清理。成品不因失败或取消删除。
- 导航和快捷键固定，内容滚动；最低 52×20，内容需要更多空间时提示扩大窗口。支持语言切换、缩放和无颜色终端。

## 标题与导航样式

顶部靠上排列：空一行、三行紧凑字符 Logo、空一行、Tab 栏、空一行、原有内容。Logo 和 Tab 按终端字符显示宽度水平居中。Tab 间使用三个空格；选中项保持方括号、强调色和加粗，其他项使用弱文字色。不更改终端字体。

窗口不足 70 列或 24 行，或内容最小高度无法与完整标题共存时，收起装饰留白，使用单行 YTDock 加 Tab 栏。内容与快捷键优先；仍沿用原有最低尺寸提示。每次重绘根据当前窗口和翻译文本重新布局，页面状态和键绑定不变。

实际验证：42 项 UI、语言及全屏测试通过；覆盖英文/中文四 Tab、80×30 常规布局、52×20、65×30、100×20 紧凑布局、缩放返回、无颜色终端及既有双向切换与取消清理。已查看渲染网格导出的英文下载页和中文字幕页文本，验证居中与间距。PTY 正常/异常退出恢复通过。未逐一检查各终端软件和字体的视觉差异；本轮不重新打包。
